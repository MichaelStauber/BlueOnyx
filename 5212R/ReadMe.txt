BlueOnyx 5212R:
===============

This is the development code tree for BlueOnyx 5212R for EL10 with the modernized CodeIgniter and Admserv-PHP-8.3

The work here is done in preparation for the eventual release of AlmaLinux 10.0, which will probably have PHP-8.3
or newer. The intent is to get base-alpine and the CodeIgniter included within modernized in so far that they work
with a state of the art PHP version. With the intent to backport it to 5211R and 5210R, too.
